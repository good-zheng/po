项目采用多进程单体仓库结构，三个子模块按职责分离：
- java_server/po 提供 RESTful API（Spring Boot，端口 8080，上下文路径 /api），负责用户认证、菜谱及分类 CRUD，使用 MyBatis-Plus + JPA 双 ORM 访问 MySQL，并通过 Redis + JWT 实现鉴权。
- py_server 提供 FastAPI 服务（默认端口 5090）：REST 挂 /api 前缀（健康检查与内存 CRUD /api/items），WebSocket 走 /ws/chat 并以 token/done/pong/error 帧协议流式输出；LangGraph 智能体为规划项。
- web_client 包含两个独立前端：po-admin（Ant Design Pro）用于管理后台，shadcn-admin（TanStack Router + shadcn/ui）用于主业务界面；两者均通过 axios baseURL '/api' 调用后端，并在请求拦截器中自动附加 Bearer Token，在 401 时清空本地状态并跳转登录页。
- 跨进程通信契约：Java 后端统一返回 { code, message, data } 包装结构，前端据此做错误处理；JWT secret 由 Java 侧生成并校验，前端仅持有 token 不解析签名。
- 共享基础设施：MySQL 作为持久化存储，Redis 用于会话/缓存，日志统一输出到各服务 logs 目录。
