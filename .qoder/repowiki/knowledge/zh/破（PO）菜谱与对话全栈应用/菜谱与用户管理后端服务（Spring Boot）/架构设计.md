模块为标准的 Spring Boot Web 应用，入口 `PoApplication` 通过 `@SpringBootApplication` 扫描 `com.goodzheng.po` 包。代码按职责分层组织：`controller/` 暴露 `/api/auth`、`/api/user`、`/api/recipe*` 等 REST 端点；`service/` 定义业务接口，`service/impl/` 提供具体实现；`repository/` 继承 JpaRepository 或 MyBatis-Plus Mapper 访问数据库；`entity/` 使用 JPA `@Entity` 映射到 MySQL 表（如 `sys_user`），并配合 Lombok `@Data` 简化代码；`dto/` 封装请求/响应对象（统一通过 `Result<T>` 包装返回）；`util/JwtUtil` 基于 jjwt 0.12.6 生成/校验 JWT，密钥与过期时间由 `application.yaml` 的 `jwt.*` 注入。数据层同时引入 `mybatis-plus-spring-boot4-starter` 与 `spring-boot-starter-data-jpa`，JPA 配置 `ddl-auto: update` 自动建表，Redis 通过 Jedis 客户端连接。监控通过 Actuator 暴露 health/info/metrics/prometheus 端点，日志输出至 `logs/application.log`。
