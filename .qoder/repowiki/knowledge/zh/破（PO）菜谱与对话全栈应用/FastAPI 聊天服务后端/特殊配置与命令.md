依赖安装：`python -m venv .venv` 后 `./.venv/Scripts/python.exe -m pip install -e ".[dev]"`（依赖声明于 `pyproject.toml`，无 requirements.txt）。启动：`./.venv/Scripts/python.exe -m uvicorn app.main:app --reload --port 5090`（免激活 venv 写法；激活需先 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`）。测试：`./.venv/Scripts/python.exe -m pytest`。配置经 `.env`（前缀 `PY_SERVER_`，见 `.env.example`）：HOST、PORT、CORS_ORIGINS。端口被占报 WinError 10013 时：`Get-NetTCPConnection -LocalPort 5090 -State Listen` 查 PID 再 `Stop-Process -Id <PID> -Force`。
