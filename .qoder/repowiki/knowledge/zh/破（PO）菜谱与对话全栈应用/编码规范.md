- 所有后端接口统一返回 { code, message, data } 三元包装结构，前端 axios 响应拦截器据此判断成功/失败
- 前端通过全局 axios 实例在请求头自动注入 Authorization: Bearer <token>，401 时清除本地 auth-store 并重定向至登录页
- Java 后端 controller/service/repository/entity/dto 分层清晰，每个业务域（用户、菜谱、分类）遵循相同包结构
- 配置集中存放于 application.yaml / .env，敏感信息（数据库密码、JWT secret、LLM Key）一律走环境变量
