### 菜谱
- 定义：项目核心业务实体，代表一道菜，包含基础信息（标题、描述、封面图、难度、耗时、份数）、分类（category_id）、标签（tags JSON）、作者（author_id）、可见性（is_public）、点赞数（likes_count），以及与食材清单（recipe_ingredient）和烹饪步骤（recipe_step）的一对多关联。支持软删除（deleted_at）。
- 别名：Recipe、做菜

### 菜谱分类
- 定义：对菜谱进行功能/菜系/饮食方式维度的归类，包含名称、emoji 图标、描述、排序权重（sort_order）和软删除标记。内置 25 条常用分类（家常菜、湘菜、川菜、素食、减脂餐等），通过 `GET /api/recipe-categories` 公开接口供前端动态加载。
- 别名：RecipeCategory、分类

### 软删除
- 定义：删除记录时不物理移除，而是将 `deleted_at` 字段设为时间戳，查询时过滤已删除记录。项目在 user、recipe、recipe_category 等实体上统一采用此策略。
- 别名：deleted_at

### _authenticated 路由组
- 定义：TanStack Router 中以 `_authenticated` 命名的路由分组，其 `route.tsx` 中的 `beforeLoad` 钩子负责校验 JWT token（无 token 或过期则重定向至 `/sign-in?redirect=...`），该组下所有子路由自动受保护。
- 别名：受保护路由、认证路由

### Token 过期判定
- 定义：通过解码 JWT payload 检查 `exp` 字段是否过期，并提前 30 秒判定过期（避免边界情况）。当 axios 响应返回 401 时触发 logout 流程并跳转登录页。
- 别名：JWT 过期、isTokenExpired

### 离线模式
- 定义：py_server 的历史概念（Flask + LangGraph 时代）：未配置 `OPENAI_API_KEY` 时智能体自动降级为 `FakeListChatModel`，无需真实 LLM Key 即可联调。当前 FastAPI 实现无 LLM 依赖（echo 模拟流式）；LangGraph 回归时应延续此降级约定。
- 别名：FakeListChatModel、降级
