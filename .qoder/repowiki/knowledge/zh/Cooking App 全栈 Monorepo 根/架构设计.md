仓库采用 pnpm monorepo 结构：`pnpm-workspace.yaml` 将 `apps/*`、`apps/*/cloudflare-worker`、`packages/*` 纳入同一工作区，顶层 `package.json` 暴露 `api/start`、`chat:start`、`mobile:start`、`admin:dev` 等子命令作为跨子模块的统一入口。

运行时由根级 `docker-compose.yml` 串联五类服务（MySQL 8.4、Redis Stack、Spring Boot API、FastAPI Chat、Nginx 网关），环境变量从 `.env` 注入；`COOKING_API_BASE_URL=http://api:8080/api` 让 chat 在容器内访问 api，web 反向代理到 api/chat。

脚本层 `scripts/run-service.mjs` / `run-mobile.mjs` / `run-sh.mjs` 是 Node 包装器，屏蔽 Windows/Mac/Linux 差异并复用同一套 deploy-* 脚本；`tools/` Python 脚本负责把 seed/*.json 转为 MySQL 种子 SQL 与静态资源，供 API 启动时初始化数据。

基础设施层 `infra/` 集中 Nginx 网关配置、GitHub Actions CI 流水线与 Husky + lint-staged + commitlint 本地 Git hooks，统一质量门禁与部署流程。
