本模块由三块互不依赖的静态配置组成：
- `infra/nginx/nginx.conf`：作为容器内唯一入口（端口 80），按 URL 前缀分流——`/ws/chat` 走 FastAPI WebSocket（chat:5090）、`/api/items` 及 `/api/health` 走 FastAPI REST、其余 `/api/**` 走 Spring Boot（api:8080，已含 context-path）、根路径 `/` 提供 Umi SPA 静态资源并回退到 `index.html`；通过 upstream 与 `map $http_upgrade` 实现长连接与 gzip。
- `.github/workflows/ci.yml`：定义四个并行 job（frontend / mobile / api / chat），分别基于 pnpm+Node22、Expo、Java17+Maven、Python3.11+pytest 构建，并在 API job 中通过 GitHub Actions services 拉起 MySQL 8.4 与 Redis 7 作为测试依赖。
- `.husky/`：本地开发钩子，`pre-commit` 触发 `lint-staged`，`commit-msg` 触发 `commitlint`，均通过 `pnpm exec` 调用工作区脚本。
依赖方向单向向外：CI 与 husky 仅驱动仓库内各服务目录，nginx 配置仅声明上游服务名（chat/api）供 docker-compose 解析。
