本模块为纯脚本型工具集合，按职责拆分为四个子任务：
- `seed-sql.py`：读取 `services/api/recipe/src/main/resources/seed/*.json`，结合 `ingredient-images.json` 映射，输出多份 `data-*.sql`（按菜系分片），同时校验封面图存在。
- `seed-ingredients.py`：从所有 recipe JSON 中抽取食材名，通过内置 `IMG` 白名单 + `ALIAS` 别名表归一化为统一 slug，输出 `ingredient-images.json` 与供批量 AI 绘图用的 `ingredients-image-list.tsv`。
- `seed-img.py`：调用 Pillow 把 `vibe_images/` 下的 PNG 源图转成 JPEG，按前缀分别写入 covers 与 ingredients 静态目录。
- `seed-backfill.py`：针对旧版已入库的 11 道菜，基于 `DB_NAMES` / `EXTRA` 手工映射生成 `data-ingredient-backfill.sql` 与 `data-cover-backfill.sql`，仅更新 NULL 字段以保证幂等。
- `cook-alert-sound.py`：纯标准库（wave/math/random）合成 44.1kHz/16bit 单声道 WAVE，用 Goertzel 自检基频分音能量，输出到 `apps/cooking-app/assets/sounds/step-done.wav`。
依赖方向单向向外：本模块只读仓库其他路径的 seed 数据与图片源，不反向依赖业务代码；各脚本之间无相互 import，通过共享的 `seed/ingredient-images.json` 作为隐式契约耦合。
