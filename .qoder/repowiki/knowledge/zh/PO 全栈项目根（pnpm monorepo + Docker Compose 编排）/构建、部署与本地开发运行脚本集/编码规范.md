- Bash 脚本通过 `${VAR:-default}` 形式声明可覆盖的环境变量（REGISTRY/NAMESPACE/REPO/TAG/PLATFORM/USE_OFFICIAL_IMAGES），并以 set -euo pipefail 开启严格模式。
- Node 脚本通过 `dirname(fileURLToPath(import.meta.url))` 计算仓库根目录，再基于相对路径拼接 services/apps 子项目路径，避免对当前工作目录的假设。
- 跨平台命令执行统一封装：Windows 下用 shell=true 并自行 quoteShellArgument 转义参数，非 Windows 下直接传参数组，以避免 Node DEP0190 警告。
- 外部工具（JAVA_HOME、ANDROID_HOME、BASH_BIN）采用候选列表回退策略（环境变量 → 默认位置 → 抛出明确错误信息）。
