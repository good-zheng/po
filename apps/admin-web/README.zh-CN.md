# 本项目文档在 [`README.md`](./README.md)

本仓库的 `apps/admin-web/README.md` 已被改写为**中文的项目文档**（路由、环境、请求约定、部署、
已知遗留），所以这份 `README.zh-CN.md` 不再单独维护内容，避免两份中文互相漂移。

保留文件的理由：它是 Ant Design Pro 模板的原始中文说明，`package.json` 的 `create-umi.ignore`
里仍列着 `README.*.md`，上游模板对照时需要一个落点。想看模板自带的中英文档，
内容在 [`docs/cheatsheet.zh-CN.md`](./docs/cheatsheet.zh-CN.md)。
