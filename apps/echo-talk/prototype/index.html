言外 EchoTalk · 交互原型

对应 PRD：apps/echo-talk/PRD.md · M0–M2 关键流程

演示控制

进入即「录音中」——对应 PRD F1 默认开始录入。也可以直接在输入框打字后点发送，走 F7 文字输入链路。

这版原型验证什么

  • 转写分层：灰字起草 → 黑字定稿，定稿才触发分析
  • 段级触发：静音 1.2s / 满 30s 成句后才调 Agent，不逐字调用
  • 说话人：顶部切换条切到「我」时只记录不分析，气泡靠右
  • 洞察结构：真正想要 / 潜台词 / 情绪 / 风险四段
  • 建议三分：稳妥 · 共情 · 推进，可朗读、可换一批
  • 留存：结束自动生成标题并进入历史，可回看完整对话流

还没做的（M3 及以后）

  • 真实录音与讯飞 ASR 接入
  • 真机 60s 分段重连、10 分钟续录的表现
  • 噪声态、断网态、转写纠错后的重分析
  • 场景预设对 prompt 的实际影响
